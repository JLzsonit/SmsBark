iPhone 短信，秒推到另一台 iPhone

收到短信 → 快捷指令自动调起「转发短信到 Bark」→ 关键词拦截判定 → Bark 推送。原生 SwiftUI，纯本地运行，不收集任何数据。

它做什么

iOS 不允许第三方 App 读短信，所以「收到短信」交给系统快捷指令，剩下的事全由本 App 打理。

🎯

关键词拦截

黑名单 / 白名单双模式，验证码、广告一律不发到另一台手机；全角半角、空格自动归一化。

🧾

运行记录

动作每跑一次都留下记录：收到什么、判没拦、Bark 返回什么。配不通时一眼看出卡在哪一步。

🫧

液态玻璃界面

iOS 27 SDK 编译，标签栏与系统 App 同款玻璃质感，滚动自动收起。

🛡️

隐私优先

配置全存本机 UserDefaults，无服务端、无统计、无埋点，唯一的网络请求是你自己配的 Bark。

三步装到手机

IPA 是未签名包，需要自签一次（免费 Apple ID 就行）。

下载 IPA

点上面的下载按钮（GitHub 公开直链，无需登录），或把链接转发给朋友。下载后建议核对 SHA256（见页脚）。

签名安装

电脑装 Sideloadly 或 AltStore（Windows 可用），填你的 Apple ID 免费签名后安装到 iPhone；支持 TrollStore 的系统可以直接永久安装。

信任开发者

首次打开若提示不受信任：设置 → 通用 → VPN 与设备管理 → 信任你的开发者证书。免费签名有效期 7 天，到期重签即可。

⚠️
装完 App 先去「推送」页填好 Bark 服务器地址和 Device Key，点「测试推送」确认另一台 iPhone 能收到，再往下配自动化。

快捷指令四步搭完（iOS 27 实测）

装好 App 后，快捷指令里能直接搜到「转发短信到 Bark」动作，照下面点即可。

新建自动化，触发条件选「通知」

发件人留空＝所有短信都转发。

快捷指令 → 自动化 → ＋ → 通知 → 我收到来自 信息

添加动作

添加操作 → 搜「SmsBark」→ 转发短信到 Bark

接上两个变量（唯一容易点错的一步）

  • 点「发件人」框 → 面板里点「快捷指令输入」→ 轻点「输入快捷指令的信息」
  • 类型选「通知」→「获取」里选「发件人」
  • 「短信内容」框重复同样路径，最后「获取」里选「正文」

关掉「运行前询问」→ 完成

改成立即运行。之后收到的短信就会自动转发了。

✅
拦截关键词在动作里自动生效，快捷指令里不用加任何判断动作。参数框里永远只用「选择变量」，不要用键盘打字——打进去的是固定文字。

常见问题

为什么不能全自动创建自动化？
苹果没有开放"替用户创建自动化"的任何接口，触发器和动作都无法由 App 预填——任何 App 声称能全自动创建都是假的。本页的四步已经是最短路径。
拦了关键词为什么另一台手机还是响？
打开 App「拦截」页最下面的「运行记录」：显示"已拦截"说明规则生效了（被拦的不会推送）；显示"内容为空"说明自动化里「短信内容」没接到「快捷指令输入 → 正文」；一条记录都没有说明自动化没调到动作，去检查触发器开关和「运行前询问」。
iMessage / 验证码也会转发吗？
iMessage 同样会触发自动化；验证码短信可以在「拦截」页加关键词（黑名单模式）拦掉，或改白名单模式只放行需要的短信。
会耗电 / 上传我的短信吗？
没有后台常驻，短信到达那一刻快捷指令发一条 GET 请求就结束。App 本身不收集任何数据，配置只存在这台设备上。
签名 7 天到期怎么办？
用 AltStore 开着同一 Wi-Fi 会自动续签；或到期后用 Sideloadly 重新签一次。有付费开发者账号（$99/年）可以签一年。
