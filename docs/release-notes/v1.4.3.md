## 这一版改了什么

- **指引页 4 步流程按实机路径重写**，文案与系统界面完全对齐：
  1. 快捷指令 → 自动化 → 选「**通知**」→「**我收到来自 信息**」
  2. 添加操作 → 搜「短信转发」→ 选「**转发短信到 Bark**」
  3. 点「发件人」/「短信内容」→ 面板里点「快捷指令输入」→ 轻点「输入快捷指令的信息」→ 类型选「**通知**」→「获取」里分别选「**发件人**」和「**正文**」
  4. 关掉「运行前询问」→ 完成
- 第 3 步单独做成高亮子清单，四个小步骤逐条列出来，不用再自己猜括号该点哪里。
- 「一键创建」卡片下方的清单同步为这 4 条；「复制步骤」按钮复制出去的也是这套文案。
- FAQ 同步：解释了「输入快捷指令的信息」就是「快捷指令输入」被点开后的名字，以及类型/获取两栏该怎么选。
- 其余功能未改动：关键词拦截、运行记录、液态玻璃标签栏、快速指令动作全部沿用 v1.4.x。

## 为什么之前一直点不通

旧指引写的是「选「信息」」和「获取 → 内容」，但 iOS 27 的快捷指令里，这个自动化交给动作的输入类型显示为「**通知**」，正文属性叫「**正文**」。名字对不上，参数面板里就怎么翻都找不到，最后只能把整条消息塞进去，导致短信内容为空、关键词永远匹配不上、Bark 那边看起来像没触发。这次把字对齐之后就通了。

## 安装后照这个顺序验证

1. 装好 App，打开「推送」页填 Bark 的服务器地址和 Device Key，点「测试推送」确认另一台 iPhone 能收到。
2. 进「拦截」页加几个要拦的关键词（黑名单模式）。
3. 进「指引」页，按 4 步建自动化；接变量时严格用「获取」里的「发件人」和「正文」。
4. 用另一台手机发一条带关键词的短信：
   - 概览页最上面「最近一次动作」显示 **已拦截（命中关键词“××”）** → 全部打通；
   - 显示 **已推送** 且内容是短信原文 → 关键词和正文没对上，把原文粘进「拦截」页的测试框复核；
   - 显示「还从没执行过」→ 自动化没调到动作，回「指引」页检查触发器开关和「运行前询问」。
