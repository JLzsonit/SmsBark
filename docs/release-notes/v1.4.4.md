## 这一版改了什么

- **全新应用图标**：双气泡母题——前层实心白气泡带语音尾巴，后层半透明玻璃气泡右上错位，系统蓝→紫渐变打底，符合 iOS 27 液态玻璃设计方向。
- **三套外观齐备**：
  - 浅色：蓝紫渐变底 + 白色实心前泡；
  - 深色：深色底，玻璃后泡与细节用品牌紫提亮，暗光下不发黑；
  - 着色（Tinted）：透明底灰度分层，后泡保留半透明层次，跟随系统主题色。
- **应用更名**：显示名、界面导航标题、快捷指令动作提示、指引页搜索词全部由「短信转发」改为 **SmsBark**。
- **新增项目简介文档** `docs/introduction.md`（中英双语）：完整介绍这是一台 iPhone 通过快捷指令自动化把短信经 Bark 推送到另一台 iPhone 的客户端。
- 其余功能未改动：Bark 推送、关键词拦截、运行记录、快捷指令自动化流程全部沿用 v1.4.x。

## 安装后验证图标

1. 装好后在主屏幕长按 → 编辑 → 自定，切换浅色 / 深色 / 着色三种外观，确认图标三种模式下层次都清晰。
2. 着色模式下前泡应保持白色实心、后泡呈半透明灰度，不与背景糊成一坨。

## 校验下载完整性

```bash
shasum -a 256 SmsBark-unsigned.ipa   # 和 .sha256 文件里的值一致即可
```
